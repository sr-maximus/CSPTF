# Safe examples

All examples are fictional and designed for an isolated lab or private testnet. They do not contain live targets, private keys, exploit payloads or customer data.

Included examples:

- `assessment-manifest.json`: fictional assessment scope, profile selection and planned tests.
- `evidence-record.json`: example of a structured evidence record tied to a CSPTF test.
- `finding.json`: fictional finding linked to a controlled bridge replay validation.
- `test-record-bridge-replay.md`: safe test record showing procedure, evidence, result and limitations.
