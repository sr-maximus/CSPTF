# CSPTF core framework

This directory contains the normative and methodological core of CSPTF.

Normative terms:

- **MUST / DEBE:** mandatory for the stated profile or claim.
- **MUST NOT / NO DEBE:** prohibited.
- **SHOULD / DEBERÍA:** expected unless a documented risk-based exception exists.
- **MAY / PUEDE:** optional.

Order of use:

1. Charter and scope
2. Rules of Engagement
3. Lifecycle
4. Assurance profile
5. Evidence and risk
6. Domain/test selection
7. Findings, reporting, remediation and retest
