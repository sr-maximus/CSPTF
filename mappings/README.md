# CSPTF mappings

Mappings reduce duplication and help assessment teams reuse specialized sources. They do **not** mean that CSPTF control completion proves compliance with the mapped source.

Mapping status:

- `proposed`: author mapping awaiting independent review;
- `reviewed`: reviewed by a subject-matter expert;
- `verified`: approved through project governance;
- `deprecated`: retained for traceability but no longer current.

The v0.1 crosswalk is thematic at domain/tactic/function level. Technique- and requirement-level mappings are a v0.2 workstream.
