# Research basis

The research directory records how CSPTF was derived and how it should be validated.

- `research-methodology.md`: source selection and synthesis.
- `gap-analysis.md`: comparison of public frameworks.
- `validation-plan.md`: expert, empirical and reliability validation.
- `source-register.csv/json`: primary standards and papers.
- `claims-evidence.csv`: traceability for major design claims.
